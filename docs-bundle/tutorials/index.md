# Tutorials

Learning-oriented walk-throughs for readers new to okf-loom.
Read each one top to bottom and reproduce every step in order.

The tutorials build on one another, but each one stands alone — start
wherever your goal sits.

## Clone and verify

* [Use okf-loom from a clone](/tutorials/install.md) — from zero to a cloned repo, loaded local skills, and your first `scripts/okf-loom validate`.
* [Author your first bundle](/tutorials/first_bundle.md) — from an empty directory to a small valid bundle.

## Work with the studio and the agent

* [Use the live studio](/tutorials/live_studio_basics.md) — serve a bundle, navigate the viewer, post a comment.
* [Direct the agent loop](/tutorials/author_with_agent.md) — `scripts/okf-loom wait`, claim, write via mutators, resolve.

## Where to go after these

Once a tutorial feels comfortable, the same tasks at a faster pace live in
the [/how-to/](/how-to/index.md) quadrant, and the machinery behind each
step is described in the [/reference/](/reference/index.md) quadrant.

For the why behind okf-loom's shape, see the
[/explanation/](/explanation/index.md) quadrant.
