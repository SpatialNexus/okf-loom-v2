# Supported currencies

| Code | Name | Symbol |
|---|---|---|
| USD | US Dollar | $ |
| EUR | Euro | € |
| GBP | British Pound | £ |
| JPY | Japanese Yen | ¥ |

# Notes

All [orders](/tables/orders.md) settle in one of the above. Refunds must
be issued in the original currency per the
[refund flow](/playbooks/refund_flow.md).
